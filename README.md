🌦️ CLIMATE SCOPE — Global Weather Trends & Extreme Weather Events
A Power BI Dashboard Project by Sakshi Zagade

📌 Overview
Climate Scope is an interactive Power BI dashboard designed to analyze global weather conditions using real‑world weather data from 2024–2025.
The dashboard provides insights into temperature trends, humidity levels, wind speed variations, and weather conditions across different countries.

This project is structured into two dashboard pages, each offering a unique analytical perspective.

🚀 Features
Page 1 — Global Weather Overview
🌍 Global Temperature Heat Map
🇺🇸 U.S. State Temperature Map
📊 Top Countries by Average Temperature
📉 Global Temperature Trend (Year-wise)
⚡ Temperature vs Humidity Scatter Plot
